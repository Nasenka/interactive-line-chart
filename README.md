## Запуск проекта

1. Установить зависимости: `npm i`
2. Запустить приложение `npm run dev`

## Стэк

1. React v19
2. TypeScript v5,
3. Vite v7
4. Node.js v24
5. Библиотека Recharts v3
6. CSS Modules

## Функции

1. Селектор вариантов с выбором, какие данные отображать
2. Селектор переключения День/Неделя
3. Селектор типов графиков
